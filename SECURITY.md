# Sicherheitsrichtlinie / Security Policy

## Lücke melden / Reporting a vulnerability

Bitte **vertraulich** über GitHub melden: **Security → Report a vulnerability**
(https://github.com/obimokenobix/elektron-gx/security/advisories/new) – keine öffentlichen Issues.

Please report **privately** via GitHub Security Advisories (link above). Do not open public issues for security problems.

- Eingangsbestätigung angestrebt innerhalb von 7 Tagen / we aim to acknowledge within 7 days
- Kritische Lücken haben Vorrang; Fixes kommen über die automatischen Updates / critical issues first, fixes ship via auto-update
- Nennung als Finder auf Wunsch / credit on request
- Bitte 90 Tage Zeit bis zur Veröffentlichung von Details / please allow 90 days before disclosure

## Unterstützte Versionen / Supported versions

Nur die neueste Version erhält Sicherheitsupdates. / Only the latest release receives security fixes.

## Außerhalb des Umfangs / Out of scope

- Fehler in Chromium → https://bughunters.google.com/report (fixes reach Elektron through Electron)
- Erweiterungen anderer Hersteller / third-party extensions
- Angriffe mit bereits vorhandenem Zugriff auf den PC, Social Engineering

## Safe Harbor

Forschung in gutem Glauben nach diesen Regeln (nur eigene Konten und Daten, keine Störung von Diensten, angemessene Frist) führt zu keinen rechtlichen Schritten.
Good-faith research following these rules will not face legal action.

Vollständige Richtlinie / full policy: https://obimokenobix.github.io/elektron-gx/sicherheit.html
