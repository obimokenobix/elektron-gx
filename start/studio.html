Elektron Studio

So geht's: Rechtsklick oder Leertaste fügt Nodes hinzu. Zieh vom Punkt rechts an einem Node zu einem Punkt links am nächsten. Alles, was am Ende in Ausgabe ankommt, siehst du oben. Bilder aus dem Internet: Rechtsklick auf ein Bild → „Bildadresse kopieren“ und im Node einfügen.

Abläufe

Ein Ablauf beginnt mit einem Auslöser (rot) – z. B. „Wenn eine Seite geöffnet wird“. Verbinde den weißen Pfeil mit Aktionen (blau) oder Bedingungen (lila). Änderungen werden automatisch gespeichert und sind sofort aktiv.

Zum Ausprobieren: Knopf ▶ Jetzt testen an einem Auslöser.
